# Ravi Job Fit Analyzer

## Install
Upload `ravi-job-fit-analyzer.zip` in Claude under Customize > Skills, enable the skill, and evaluate a complete job posting.

## Test prompt
Evaluate this role against my Career Evidence Bank. Give me the fit score, confidence, decision, evidence mapping, gaps, practical constraints, and exact next action.

## Maintenance
The bundled Career Evidence Bank is a portable Markdown source. Replace it only with a newer user-approved version, and preserve the claim guardrails.
