# Target Role Matrix

## Application Manager
Prioritize enterprise application ownership, COTS/SaaS lifecycle, integrations, releases, production support, ITSM, incidents/problems, vendors, stakeholders, modernization, and reliability.

## Technical Delivery Manager
Prioritize end-to-end delivery, cross-functional leadership, schedules, milestones, dependencies, risks, releases, production readiness, technical credibility, clients, executive reporting, and issue removal.

## Information Technology Manager
Prioritize technology/application operations, ITSM, cloud/infrastructure breadth, vendors, strategy, governance, leadership, security awareness, people management, budget, and resources. Screen carefully when direct reports or budget ownership are mandatory.

## Information System Manager
Prioritize enterprise/business systems, application lifecycle, integrations/data, business-IT alignment, service reliability, modernization, architecture, vendors, and governance.

## Software Engineering Manager
Prioritize software delivery, architecture, APIs/cloud/DevOps, engineering practices, mentoring, hiring, product collaboration, and formal people/performance management. Formal line management is a known evidence gap.

## Technical Services Manager
Prioritize ITSM/service delivery, application/technical operations, SLA, support, incidents/problems/RCA, reliability, changes/releases, escalations, cloud/infrastructure awareness, and stakeholder/vendor management.
