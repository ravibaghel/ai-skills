# Role Relevance Matrix

## Application Manager
Research: application portfolio, COTS/SaaS platforms, modernization, integrations, service management, vendors, reliability, business ownership.

## Technical Delivery Manager
Research: transformation initiatives, delivery environment, cloud/platform programs, engineering interfaces, dependencies, governance, production readiness, client/business stakeholders.

## Information Technology Manager
Research: technology operating model, enterprise applications, IT services, cloud/infrastructure, governance, vendors, security/regulatory context, leadership scope.

## Information System Manager
Research: core business systems, integrations/data flows, system lifecycle, modernization, business/IT alignment, reliability, governance.

## Software Engineering Manager
Research: products/platforms, engineering practices when publicly documented, architecture/cloud/API themes, development model, AI/data/security signals, leadership expectations.

## Technical Services Manager
Research: service delivery, operations, reliability, SLAs, support model, incident/problem/change themes, monitoring, infrastructure/cloud, vendor/customer relationships.
