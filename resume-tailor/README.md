# Ravi Resume Tailor

Upload this ZIP in Claude under Customize > Skills and enable it alongside Ravi Job Fit Analyzer.

Recommended first test:
1. Run Job Fit Analyzer on a complete job posting.
2. For a result of APPLY or PRIORITY APPLY, ask: "Use Ravi Resume Tailor to create a truthful ATS resume. Include an Evidence Trace and do not overwrite my master resume."

The bundled evidence bank is portable Markdown. Replace it only with a newer user-approved version.
