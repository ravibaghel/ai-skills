# ATS and Formatting

- Use standard headings: Professional Summary, Core Skills, Professional Experience, Education, Certifications.
- Avoid decorative icons, text boxes, multi-column layouts, charts, photos, graphics, headers/footers containing essential content, and complex tables in the ATS version.
- Use conventional fonts and simple bullets.
- Include job-description terminology only when factually supported.
- Prefer exact supported phrases such as technical delivery, production readiness, APIs, integrations, ITSM, incident management, risk management, and stakeholder management.
- Do not repeat keywords unnaturally.
- Keep dates and employers easy to parse.
- Preserve a clean chronological employment history.
- If both polished and ATS versions are requested, create separate files and preserve identical facts.
