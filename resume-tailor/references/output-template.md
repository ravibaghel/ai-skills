# Resume Tailor Output

## Tailoring Strategy
- Job and company
- Job Fit decision and confidence
- Closest target role
- Primary positioning
- Top requirements
- Best evidence
- Genuine gaps
- ATS keywords approved for use
- Content to reduce/remove

## Tailored Resume
Provide or create the full resume. Preserve contact data from the approved master resume.

## Evidence Trace
For each materially changed claim:
- Tailored text
- Evidence source/project
- Evidence class A/B/C
- Transformation type: selected, reordered, clarified, condensed, or terminology aligned
- New factual claim introduced: No

## Unsupported Requirements
List required/preferred qualifications not supported. Do not add them to the resume.

## Interview Follow-ups
List claims that need context or metrics that need verification.

## Final Audit
State that names, titles, dates, education, and factual boundaries were preserved. Identify any item still requiring confirmation.
