# Resume Tailoring Rules

1. Preserve history, change emphasis.
2. Use only verified evidence.
3. Prioritize the top requirements rather than copying the entire job description.
4. Place strongest relevant evidence in the summary and first bullets.
5. Keep actual employer titles unchanged.
6. Use role-aligned headlines as positioning, not as claimed formal titles.
7. Reorder skills by relevance but do not add unsupported technologies.
8. Use the Seaware story for current application leadership, production readiness, cloud, APIs, incidents, releases, and hypercare.
9. Use WideOrbit for transformation, migration, phased cutover, data integration, change/training, and go/no-go decisions.
10. Use the Technical Lead story for engineering-team leadership, SDLC, Agile, mentoring, and delivery predictability.
11. Mark uncertain metrics for verification.
12. Create a new tailored file; preserve the master resume.
