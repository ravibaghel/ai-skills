# Prohibited Transformations

Bad: "Managed 10 direct reports."
Reason: Evidence supports cross-functional coordination, not direct reports.

Bad: "Owned staffing and resource allocation."
Reason: Resource-planning ownership is not established.

Bad: "Architected enterprise CI/CD platforms using Azure DevOps, Harness, and Jenkins."
Reason: Evidence supports deployment coordination.

Bad: "Led a greenfield AI platform implementation on Kubernetes."
Reason: Greenfield, production AI, and Kubernetes evidence are absent.

Bad: "Led a full lifecycle ERP implementation."
Reason: WideOrbit migration is not ERP evidence.

Bad: "Delivered measurable performance improvement by staggering API calls."
Reason: Recommendation is supported; measured outcome is not documented.

Bad: "Owned a multimillion-dollar technology budget."
Reason: Budget ownership is explicitly unsupported.
